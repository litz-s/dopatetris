05 NOTES 実装の前提
PERFORMANCE
アニメは transform / opacity / filter のみ。同時パーティクル上限 120個、超過分は破棄。60fps維持を優先し、フィーバー＋爆発同時発火時はパーティクルを50%間引き。prefers-reduced-motion で振幅・点滅を1/4に。
TIMING BASE
全モーションは BPM 174（1拍 ≒ 345ms）を基準グリッドに。UI跳ね=1/2拍、点滅=1拍、フィーバー脈動=2拍。ゲーム進行と演出のテンポを揃えて音ゲー感を作る。
SOUND HOOK（後日）
発火点だけ先に確定：移動 / 回転 / ソフト着地 / ハードドロップ / 各列ポップ（左→右で音程上昇）/ 爆発 / 重力着地 / フィーバー突入・終了 / コンボ加算（段階でピッチ+）。実装時にフックを空関数で用意しておく。
