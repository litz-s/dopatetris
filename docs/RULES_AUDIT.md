# ルール・演出監査（2026-10-19）

この監査本文はPR #2時点の記録。後続の調整でソフトドロップは基準50マス/秒＋高速時1.25倍へ変更した。最新の速度仕様は [SPEC.md](SPEC.md) を参照。

対象の比較元: `263564ce2abb76aaf7f52e6713966d5b479fd659`（PR #1 マージ時）。
基準は現代のSRS・3コーナー方式。イベントスタック、フィーバー、重力効果、得点設計は本作の仕様として維持する。敗北条件と接地リセット上限の修正は、ユーザー確認を得て実施した。

## T-Spin Double の条件

Tで2行を消しただけでは成立しない。固定直前の**実際に成功した移動**が回転で、Tの中心の斜め4隅のうち3隅以上が埋まっていることが必要。壁と床も埋まった隅として数える。さらにTの突起が向く側の2隅が埋まっていればフルT-Spin、それ以外はMiniになる。ただしSRSの5番目の候補で成功するFin/TST系の回転はフル扱いになる。

フルT-Spinの固定で同時に消えた行数が1ならSingle、2ならDouble、3ならTriple。回転中に消えた行を累積する判定ではない。回転の後に横移動や実際の落下が成功すると回転履歴を取り消す。移動・回転の失敗や、落下距離0のハードドロップによる確定は履歴を取り消さない。[FOURの実演解説](https://four.lol/srs/t-spin/)、[SEGA公式マニュアル（7ページ）](https://cdn.cloudflare.steamstatic.com/steam/apps/1259790/manuals/tenpex_WM_210216_Steam_en.pdf?t=1633021613)を参照。

## 再現して修正した問題

| 優先度 | 問題 | 修正 |
|---|---|---|
| 高 | 空中の回転履歴が、落下距離のあるハードドロップ後にも残る | 実際に落ちた場合は回転履歴を無効化。0マス確定は維持 |
| 高 | どの壁蹴りでもMiniがフル扱いになる | 成功したSRS候補番号を記録し、5番目だけを例外とする |
| 高 | 同一入力バッチの後続操作が、開始直後の消去・重力演出中の盤面を変更する | 演出が始まった時点でそのバッチを打ち切る |
| 高 | おじゃまによる上端越えで既存ブロックが失われても、生存扱いになる | 行挿入前に押し出しを検出して敗北。敗北後の次ミノ出現も防止 |
| 中 | リセット上限に達しても、段差から離れて戻ると500msを再取得できる | 15回消費後は次の接地時に固定。空中での強制固定はしない |

### 空中回転からの誤Doubleの再現

盤面座標は左上を `(0,0)` とし、不可視2行も含む。`(5,5)` と `(3,19)` を埋める。20行目は4・5列以外、21行目は4列以外を埋める。Tを回転状態2、原点 `(4,5)` から反時計回りに回すと、SRSの2番目の候補で `(3,5)`・状態1になる。そこから14マスのハードドロップで2行消去できる。

- 変更前: **T-Spin Double** と誤判定。
- 変更後: **通常のDouble**。落下後の確定は回し込みではない。
- 別途、接地位置で回し込む本来のT-Spin Double、通常キックによるMini、5番目の候補によるフル昇格も実際のコマンド列で検証。

比較元のコードに対しても誤判定を再実行して確認した。ただし、ユーザーが以前見たプレイの入力記録はないため、その一回の原因までは特定できない。

## 維持した違い・監査の限界

得点の標準化は今回行わない、というユーザーの選択に従う。通常消去100/300/500/800、フルSpin消去800/1200/1600、B2B1.5倍は公式ウェブ版の公開表と同系統。一方、本作には次の違いがある。

- Miniは1行・2行を同じ `tspin-mini` とし、基礎点100。Mini Doubleの表示・攻撃力も独立していない。
- 消去なしSpinには得点も専用イベントも付けない。
- Perfect Clearは追加スコアを付けない。
- コンボは加算式ではなく、本作の0.15刻みの倍率。フィーバー、クローバー、爆弾等の補正が入る。
- ソフトドロップ12倍・最短35ms、1ステップ最大2マス、独自速度表と演出停止時間を維持する。
- 接地リセットは本作の「1ミノ最大15回」。より低い行へ到達した際に上限を更新する別方式は追加していない。
- 上端到達の扱いは、スポーン衝突＋今回承認されたおじゃま押し出し。不可視領域での固定をすべて即敗北にする別のLock Out方式には変更しない。

公式モバイル版ではMini Single 200、Mini Double 400、消去なしフルSpin 400などが公開されているが、作品ごとに差がある。今回の確認は公開されている説明と本作のコード・テストの照合であり、非公開の最新版Guideline全項目への完全適合認証ではない。

## 演出の変更と検証

- フィーバー: 盤面内部を3列×4段の12領域に分け、順序を飛ばしながら各領域を一巡。領域内にランダムな揺らぎを付け、90ms間隔で白い星・コミック爆発・メダルを放出。ULTRAは一度に2箇所、HIGH/MIDは1箇所。LOWとパーティクル0設定では停止。
- 消去: 各セルの白い輪郭を拡散・フェード。通常消去の左から右への順番に同期した白いスイープを追加。4行消去は既存の専用スイープに輪郭を合わせる。輪郭は装飾パーティクルより前面に描いて方向を見せる。
- 通常710ms／4行870msの消去時間、ゲームの状態更新と得点のタイミングは延長しない。
- 既存アセットを使用。画像制作や外部サービスの設定など、ユーザー側の追加作業は不要。
- 固定プール、画質設定、減らした動き、フィーバー終了後の消滅を検証。Canvas側の演出はゲーム状態を変更しない。
- 実ブラウザーで変更前／後を並べ、フィーバー・通常消去・4行消去・LOWを確認。性能は同じ盤面・同じイベントで各300フレームを比較し、別添JSONへ記録する。ブラウザーのフレーム間隔には揺らぎがあるため、全環境での60fpsを保証するものではない。
